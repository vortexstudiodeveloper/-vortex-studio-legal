Privacy Policy

Last Updated: September 1, 2026

This Privacy Policy explains how Vortex Studio handles information when you use the Vortex Studio Discord application associated with The Divided.

1. About the Application

The Vortex Studio Discord application is designed primarily to provide information about The Divided, including game codes, updates, announcements, and other game-related information.

2. Information We May Process

Depending on how the application is configured, it may process basic Discord information necessary for its operation, such as:

  • Discord user IDs
  • Discord server IDs
  • Discord channel IDs
  • Information required to provide application features

The application is not intended to collect sensitive personal information.

3. How Information Is Used

Information may be processed to:

  • Provide game codes.
  • Provide The Divided updates.
  • Send or display announcements.
  • Operate and maintain the application.
  • Improve application features.
  • Prevent abuse or misuse.

4. Information We Do Not Sell

Vortex Studio does not sell users' personal information.

5. Data Storage

The application does not intentionally collect or permanently store personal information unless storage is necessary for a feature.

If Vortex Studio introduces features that require additional information to be stored, this Privacy Policy will be updated to explain what information is collected, why it is collected, and how it is handled.

6. Discord

The application operates through Discord. Discord may independently collect and process information according to its own policies.

Vortex Studio is not affiliated with Discord Inc.
